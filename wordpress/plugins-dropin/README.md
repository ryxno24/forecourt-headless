# ACF Pro drop-in

Place `advanced-custom-fields-pro.zip` (any filename starting `advanced-custom-fields-pro`) in this folder before running `make setup` to use ACF Pro.

If no zip is found, setup installs [Secure Custom Fields](https://wordpress.org/plugins/secure-custom-fields/) from WordPress.org instead. It is a free fork of ACF that includes Flexible Content, Repeater and Options Pages, and reads the same field group JSON.

Everything in this folder except this README is git-ignored so licensed plugin files are never committed.
